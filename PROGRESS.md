## Этап 2 — реализованные задачи 2.1–2.5

### 2.1 — импорт CSV и предпросмотр

- Глобальная кнопка Import CSV доступна из обоих режимов.
- Общий Welcome Screen при отсутствии активного набора.
- Upload CSV открывает модальный интерфейс импорта. Try demo data отображается неактивным с пометкой «Скоро».
- Papa Parse разбирает локальный CSV в Web Worker.
- Предпросмотр первых 20 строк, заголовков, имени файла, общего количества строк и столбцов.
- Автоматический или ручной выбор разделителя — запятая, точка с запятой, табуляция.
- Настройка наличия строки заголовков и выбор UTF-8 / Windows-1251.
- Сообщения о пустых файлах, некорректных кавычках, строках разной длины, пустых и повторяющихся заголовках.
- Исходные значения сохраняются строками, включая ведущие нули. Недостающие поля представлены как null.
- После подтверждения импорта открывается Data View.
- Отмена повторного импорта сохраняет текущий набор.
- Сообщения и интерфейс локализованы.

### 2.2 — постоянное хранение в IndexedDB

- Dexie.js и версионируемая схема версии 1.
- datasets хранит ID набора, имя файла, параметры импорта, описание столбцов, число строк и ревизию.
- rows хранит строки по ключу [datasetId, rowId], исходный порядок и значения по стабильным ID столбцов.
- preferences в IndexedDB хранит ссылку на последний активный набор. Язык, тема и режим сохраняются в localStorage согласно отдельному требованию этапа 1.
- Поддержаны несколько независимых наборов, переключение между ними и восстановление активного набора после перезагрузки.
- Удаление набора требует подтверждения. При удалении активного набора выбирается последний импортированный из оставшихся. После удаления последнего показывается Welcome Screen.
- Импорт и удаление выполняются транзакционно. Частично записанный импорт откатывается при ошибке.
- Интерфейс показывает операции сохранения, открытия и удаления, ошибки и доступные повторные действия.

### 2.3 — таблица CSV

- TanStack Table отображает строки активного набора в Data View.
- Клиентская пагинация по 25, 50 или 100 строк.
- Общее число строк и столбцов, номер страницы, переходы на первую, предыдущую, следующую и последнюю страницы.
- Горизонтальная прокрутка для широких таблиц.
- Пустые строки и отсутствующие поля отображаются различимыми подписями.
- При смене набора таблица возвращается на первую страницу и сохраняет выбранный размер страницы в текущем сеансе.
- Перелистывание использует уже загруженные строки и не обращается повторно к IndexedDB.
- В браузере проверен набор из 50 000 строк и 20 столбцов.

### 2.4 — редактирование ячеек

- Двойной клик открывает редактор ячейки. Вход с клавиатуры доступен через кнопку ячейки.
- Enter и потеря фокуса сохраняют правку, Escape отменяет. Shift+Enter позволяет вводить перенос строки.
- Пустая строка, ведущие нули и текст сохраняются без преобразования типов.
- Неизменённое отсутствующее поле остаётся null.
- Обновляются только изменённая строка и ревизия набора в одной транзакции.
- Подтверждённое значение появляется после успешной записи. Ошибка сохраняет прежнее значение и выводит сообщение.
- Проверка ревизии предотвращает перезапись изменений другой вкладки устаревшим набором.
- Сохранённые правки восстанавливаются после перезагрузки.

### 2.5 — экспорт CSV и подсказка редактирования

- Глобальная кнопка Export CSV рядом с Import CSV. При отсутствии активного набора экспорт недоступен.
- Экспорт через Papa Parse всех строк в исходном порядке с сохранёнными правками.
- Сохраняются порядок столбцов, исходные заголовки, повторяющиеся заголовки, текст, пустые строки и ведущие нули.
- Используются исходный разделитель, UTF-8 с BOM и окончания записей CRLF.
- Имя файла получает суффикс _edited.csv.
- Кавычки, разделители и переносы строк экранируются Papa Parse.
- Если CSV импортирован без заголовков, при экспорте искусственные заголовки не добавляются.
- Диалог сообщает число отсутствующих полей, которые выгружаются как пустые CSV-поля.
- Защита от CSV Formula Injection включена по умолчанию и применяется к экспортируемым ячейкам и заголовкам.
- Диалог показывает число потенциально опасных полей и число значений, которые изменит защита.
- Отключение защиты при наличии опасных значений требует отдельного подтверждения скачивания.
- Экспорт не изменяет значения и ревизии в IndexedDB.
- Над таблицей добавлена согласованная подсказка на русском и английском языках.

### Проверка замечаний Code Review — 11 ноября 2026 года

- Измерен экспорт 50 000 × 20 на временном production-стенде с кодом проекта. Chromium 157, macOS, 10 логических потоков по navigator.hardwareConcurrency, без искусственного замедления CPU. По три последовательных прогона для исходной реализации и Worker. Синтетические строковые значения, результат 15 989 122 байта, защита включена.
- В исходной реализации подготовка занимала 24,2–27,8 мс, сериализация 81,7–101,6 мс. С формированием Blob обработка занимала 129,6–157,4 мс. Задержка таймера основного потока составляла 129,8–157,7 мс, максимальный интервал между requestAnimationFrame — 99,9–133,3 мс.
- Подготовка, подсчёт изменяемых полей, сериализация Papa Parse и создание Blob перенесены в отдельный Web Worker. Worker получает ID и ревизию и читает снимок набора через readonly-транзакцию существующего слоя Dexie. Основной поток получает только сводку и готовый Blob.
- В Worker чтение и подготовка с ответом занимали 244,5–268,4 мс, сериализация и создание Blob с ответом — 112,9–122,7 мс. Последний показатель включает передачу результата и не является отдельным замером только Papa.unparse. Задержка таймера основного потока составляла 0–0,1 мс, максимальный интервал между кадрами — 16,7–17,6 мс.
- Добавлены состояния подготовки и создания файла, отмена фонового задания при закрытии диалога, обработка ошибок Worker и повтор экспорта.
- Защита расширена на формульные префиксы после ведущих пробелов, Unicode-пробелов, BOM и управляющих символов C0/C1. Один шаблон используется для подсчёта и escapeFormulae Papa Parse. Исходные пробелы и управляющие символы сохраняются, апостроф добавляется только в защищённую выгрузку.
- Добавлены регрессионные тесты для заголовков и ячеек с такими префиксами, обычного текста с отступами, обоих режимов защиты, readonly-снимка и отказа запуска Worker с повторной попыткой.
- В production-сборке приложения проверены реальные скачивания с защитой и без неё. Отключение защиты при трёх опасных полях блокировало скачивание до отдельного подтверждения. Содержимое обоих файлов проверено, включая NUL, ведущие нули, кавычки, переносы строк и русский текст.
- После перезагрузки подтверждено сохранение исходных заголовков и значений в IndexedDB. Автоматические тесты также проверяют сохранность метаданных, ревизии и выбора активного набора при подготовке и экспорте.
- Скачанный production-экспорт большого набора проверен на 50 000 строк данных, 20 столбцов и исходный порядок.
- Поведение конкретных версий Excel и LibreOffice при открытии формул отдельно не проверялось. Измерения характеризуют использованный браузер и синтетический набор.

## Текущие ограничения

- Данные привязаны к адресу сайта и профилю браузера. Очистка данных сайта удаляет сохранённые наборы.
- Открытые вкладки автоматически не обновляют список наборов. При конфликте ревизий требуется перечитать набор.
- CSV не представляет различие между отсутствующим полем null и пустым полем. Диалог экспорта сообщает о выгрузке отсутствующих полей как пустых.
- Проверка набора 50 000 × 20 выполнена для текущих возможностей импорта, таблицы и экспорта. Производительность будущей аналитики и графиков ещё предстоит проверить.
- Workflow содержит проверки качества кода. Автоматический деплой пока не настроен.
